# Deploy on Render

The included Blueprint creates a free Docker web service. No paid AI key is required.

1. Push the repository to GitHub or GitLab.
2. In Render, choose **New + → Blueprint**.
3. Connect the repository and select `render.yaml`.
4. Enter `BRIEFING_PASSWORD` when asked; use at least 10 characters.
5. Apply the Blueprint and wait for `/healthz` to become healthy.
6. Open the service URL, sign in, and wait for the first source refresh.

Production variables:

- `BRIEFING_PASSWORD` — private password of 10+ characters
- `SECRET_KEY` — generated by Render
- `BRIEFING_PUBLIC=1`
- `BRIEFING_SCHEDULE=1`
- `BRIEFING_TZ=America/Los_Angeles`
- `BRIEFING_REFRESH_MINUTES=45`
- `DATABASE_PATH=/tmp/monday-briefing.sqlite3`

The free service sleeps after inactivity and can take roughly a minute to wake. It also uses ephemeral SQLite storage, so learner progress and archives can reset after a redeploy or infrastructure restart. The current financial radar is rebuilt automatically from free sources whenever needed.

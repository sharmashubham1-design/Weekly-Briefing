# Deploy on Render

The included Blueprint creates a free Docker web service. Its SQLite database uses ephemeral storage, so learner progress and archives can reset after a redeploy or infrastructure restart.

1. Push this repository to a private GitHub or GitLab repository.
2. In Render, choose **New + → Blueprint**.
3. Connect the repository and select `render.yaml` when prompted.
4. Enter `BRIEFING_PASSWORD` when Render asks. Use at least 10 characters.
5. Enter `ANTHROPIC_API_KEY` in Render. Do not add it to the repository.
6. Confirm the generated `SECRET_KEY`, persistent disk, and service plan, then choose **Apply**.
7. Wait for `/healthz` to report healthy, open the service URL, and sign in.
8. Confirm the banner says **Live**, choose **Generate now**, and leave the page open while the build status updates.

Exact production environment variables:

- `ANTHROPIC_API_KEY` — your Anthropic key
- `BRIEFING_PASSWORD` — a private password of 10+ characters
- `SECRET_KEY` — generated by Render; use a strong random value if setting manually
- `BRIEFING_PUBLIC=1`
- `BRIEFING_SCHEDULE=1`
- `BRIEFING_TZ=America/Los_Angeles` (change if desired)
- `BRIEFING_MODEL=claude-sonnet-5-5`
- `DATABASE_PATH=/tmp/monday-briefing.sqlite3`

Render runs one Gunicorn worker with eight threads. The in-app scheduler checks every 15 minutes. At or after 07:00 each Monday in `BRIEFING_TZ`, it starts the missing prior-week edition once and does not automatically retry a failed build.
